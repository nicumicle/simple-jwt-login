Another site calling the WordPress site (local testing only)

Used by the Playwright suite in tests/CrossSite. Each page tries to create an administrator on the WordPress site. Add ?target=http://localhost:88&m=some_username.

  • form.html - auto-submitting form POST with the JWT cookie (the reported PoC)
  • navigate.html - GET navigation with _method=POST, no Referer
  • fetch.html - background no-cors fetch with the JWT cookie
  • call.html - any REST call, described in the fragment (#call={...}, see the page)
  • cors.html - CORS call (&cred=header#jwt=... or &cred=cookie)
